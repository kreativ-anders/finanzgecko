Dokumentation

FinanzGecko ist ein lokaler Vermögenstracker: Konten anlegen, monatlich Kontostände erfassen, wiederkehrende Ein-/Ausgaben pflegen — und daraus ein Dashboard mit Verlauf, Prognose und Kennzahlen bekommen. Diese Seite erklärt den Ablauf und die wichtigsten Ansichten.

1 Genereller Ablauf

Die App gliedert sich in sechs Ansichten in der linken Navigation. Für den Einstieg ist die Reihenfolge von links nach rechts sinnvoll:

Konto anlegen → Kontostand erfassen → Fixposten pflegen → Vermögenswerte erfassen → Dashboard beobachten

Jeden Monat reicht danach ein kurzer Besuch der Ansicht Einträge, um die aktuellen Kontostände nachzutragen — das Dashboard aktualisiert sich automatisch, inklusive Verlauf, Prognose und Kennzahlen.

Alle Daten liegen ausschließlich lokal, AES-256-verschlüsselt in einer einzigen Datei auf dem Gerät. Es gibt keinen Account, keine Cloud-Synchronisierung und keinen Server.

2 Konto hinzufügen

In der Ansicht Konten werden alle Konten angelegt, die im Vermögen berücksichtigt werden sollen — etwa Girokonto, Tagesgeld, Depot, Bargeld oder Krypto-Wallets.

  • Pflichtfelder: Name, Kontotyp und Währung.
  • Bank optional wählbar — bekannte Banken schlagen automatisch eine passende Farbe vor.
  • Ohne bekannte Bank wird die Farbe des Kontotyps als Standard verwendet.
  • Bei einer vom Basiswährung abweichenden Kontowährung erscheint ein Fremdwährungs-Hinweis.

Konten lassen sich jederzeit bearbeiten. Statt endgültigem Löschen werden sie archiviert (Soft-Delete) — bereits erfasste Kontostände bleiben dabei erhalten und können bei Bedarf wiederhergestellt werden.

3 Einträge hinzufügen

Die Ansicht Einträge ist für die monatliche Erfassung gedacht: alle Konten auf einmal, für einen ausgewählten Monat. Standardmäßig ist der aktuelle Monat vorausgewählt, per Monatswechsel lässt sich aber auch rückwirkend erfasst werden.

  • Pro Konto und Monat existiert genau ein Eintrag — ein erneutes Speichern überschreibt den bestehenden Wert.
  • Leer gelassene Felder werden beim Speichern übersprungen, nicht auf 0 gesetzt.
  • Enter springt zum nächsten Konto, beim letzten Konto wird direkt gespeichert.
  • Eine Live-Zwischensumme zeigt schon während der Eingabe den Stand in der Basiswährung.
  • Ein Filter blendet Konten aus, für die der Monat bereits erfasst ist — praktisch, wenn nur wenige fehlen.

Springt ein Kontostand im Vergleich zum Vormonat unerwartet stark (z. B. eine Ziffer zu viel getippt), weist die App mit einem Anomalie-Hinweis darauf hin.

4 Fixposten erfassen

Fixposten sind wiederkehrende Ein- oder Ausgaben — Gehalt, Miete, Abos, Dividenden. Sie fließen in die Prognose und in die Netto-Übersicht auf dem Dashboard ein.

  • Neue Fixposten sind standardmäßig eine Ausgabe, können aber als Einnahme markiert werden.
  • Intervall frei wählbar (z. B. monatlich, jährlich) — die App rechnet automatisch auf ein Monatsäquivalent um.
  • Beträge werden inline bearbeitet und automatisch gespeichert (Autosave nach kurzer Tippzeit, bei Fokusverlust oder Enter).
  • Die Liste gruppiert Einnahmen vor Ausgaben und zeigt eine Summen-Übersicht.

Ist das Netto aus allen Fixposten dauerhaft negativ, macht ein Hinweis-Banner auf dem Dashboard darauf aufmerksam.

5 Vermögenswerte

Vermögenswerte sind Sachwerte ohne monatlichen Zeitverlauf — Elektronik, Möbel, Fahrzeuge. Anders als Konten wird hier nur der aktuelle Wert gepflegt, keine Historie.

  • Name und aktueller Wert sind Pflichtfelder beim Anlegen.
  • Werte werden inline bearbeitet, jede Wertänderung zählt automatisch als Neubewertung.
  • Wurde ein Vermögenswert rund sechs Monate nicht neu bewertet, markiert ihn die App als überfällig.
  • Auf dem Dashboard fließen Vermögenswerte optional, aber standardmäßig nicht in die Gesamtsumme ein.

6 Dashboard & Filter

Das Dashboard fasst alle erfassten Daten zusammen: Gesamtvermögen, Verlauf mit Prognose, Zusammensetzung über Zeit, Verteilung nach Kontotyp, Kennzahlen sowie eine Konto-Karte pro Konto mit Mini-Verlauf.

Zeitraum-Filter

Oben auf dem Dashboard lässt sich der betrachtete Zeitraum wählen (z. B. „Dieses Jahr“, „Letzte 12 Monate“ oder die volle Historie). Welche Presets zur Auswahl stehen, hängt von der vorhandenen Datenhistorie ab. Der Filter wirkt auf alle zeitbasierten Karten gleichzeitig.

  • Die Prognose ist nur sichtbar, wenn der gewählte Zeitraum bis zum aktuellsten erfassten Monat reicht.
  • Der Verteilungs-Donut zeigt immer den aktuellsten Monat innerhalb des gewählten Zeitraums.
  • Die Kennzahlen-Karte (bester/schwächster Monat, Ø-Veränderung, Höchststand) erscheint erst ab zwei Monaten Historie.

Zusätzlich erinnert das Dashboard bei Bedarf an offene Aufgaben: den aktuellen Monat erfassen, ein fälliges Backup exportieren oder überfällige Vermögenswerte neu bewerten.

7 Einstellungen

In den Einstellungen lassen sich die grundlegenden Rahmenbedingungen der App anpassen.

  • Basiswährung: Zielwährung, in die alle Dashboard-Summen umgerechnet werden.
  • Sicherheits-Informationen: Einsicht, wie und wo Daten verschlüsselt gespeichert werden.
  • Speicherort: lässt sich direkt im Dateimanager öffnen.
  • Backup: Export/Import als Klartext-JSON über native Dateidialoge; der Export-Status wird angezeigt.
  • Zurücksetzen: einzige unumkehrbare Aktion der App — erfordert eine getippte Bestätigungsphrase, kein einfacher Klick.

Globale Tastenkürzel (unabhängig von der aktuellen Ansicht):

  • Strg/⌘ + E — Backup exportieren
  • Strg/⌘ + I — Backup importieren
  • Strg/⌘ + Q — App beenden
