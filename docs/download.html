Vor einem Update kurz ein Backup exportieren. Es gibt keinen Server, von dem sich etwas zurückholen ließe — deine Daten liegen nur bei dir. Einstellungen → Backup exportieren…, ein paar Sekunden, eine Datei.

Was du bekommst

Nach dem ersten Start legst du deine Konten an und trägst monatlich die Kontostände ein. Daraus berechnet FinanzGecko dein Gesamtvermögen, den Verlauf über die Zeit und eine Prognose. Fixposten bilden wiederkehrende Einnahmen und Ausgaben ab, Vermögenswerte erfassen Sachwerte wie Fahrzeuge oder Technik. Alles entsteht auf deinem Computer — kein Nutzerkonto, keine Cloud. Alle Ansichten im Detail: Dokumentation.

Für Windows gibt es einen Installer (.exe, ab Windows 10, 64-Bit), für macOS ein Disk-Image (.dmg, Apple Silicon und Intel), für Linux ein AppImage (x86_64), das ohne Paketmanager und ohne Root-Rechte startet. So installierst du es →

Deine Daten bleiben bei dir

Alles liegt verschlüsselt in einer einzigen Datei auf deinem Computer, der Schlüssel im Schlüsselbund deines Betriebssystems. Die App sendet keine Nutzungsdaten und keine Absturzberichte. Sie geht nur in zwei Fällen ins Netz, beide erst nach deiner Entscheidung: Wechselkurse für Konten in fremder Währung, und die Suche nach einer neuen Version. Nachzulesen in der Datenschutzerklärung.

Updates

In der App: Einstellungen → Nach Updates suchen. FinanzGecko lädt auf Wunsch die passende Datei, prüft sie gegen die veröffentlichte Prüfsumme und legt sie ab, wo du möchtest — installiert wird nichts von selbst. Die Datei öffnest du dann wie beim ersten Mal; beende FinanzGecko vorher. Deine Daten bleiben dabei erhalten.
