Vor einem Update kurz ein Backup exportieren. Deine Daten liegen verschlüsselt auf deinem Rechner, der Schlüssel dazu im Schlüsselbund deines Betriebssystems. Dieser Schlüssel ist an die installierte App gebunden — ändert sich an ihr etwas Grundlegendes, etwa ihre Signatur, kann sich im Einzelfall auch der Zugriff darauf ändern. Normalerweise merkst du davon nichts. Weil es aber keinen Server gibt, von dem sich etwas zurückholen ließe, ist ein Export vorher schlicht fair: Einstellungen → Backup exportieren… — ein paar Sekunden, eine Datei.

Welche Version passt zu meinem System?

FinanzGecko ist eine native Desktop-Anwendung und wird für jede Plattform getrennt gebaut. Unter Windows lädst du einen gewöhnlichen Installer (.exe) für 64-Bit-Systeme ab Windows 10. Unter macOS bekommst du ein Disk-Image (.dmg), aus dem du die App in den Programme-Ordner ziehst; sie läuft sowohl auf Apple Silicon als auch auf Intel-Macs. Unter Linux erhältst du ein AppImage für x86_64, das ohne Paketmanager und ohne Root-Rechte auf praktisch jeder gängigen Distribution startet. Erkennt dein Browser JavaScript, hebt diese Seite die zu deinem System passende Karte automatisch hervor.

Was du nach dem Download bekommst

Nach dem ersten Start legst du deine Konten an und trägst monatlich die Kontostände ein. Aus diesen Werten berechnet FinanzGecko dein Gesamtvermögen, den Verlauf über die Zeit und eine Prognose. Fixposten bilden wiederkehrende Einnahmen und Ausgaben ab, Vermögenswerte erfassen Sachwerte wie Fahrzeuge oder Technik. Alle Auswertungen entstehen lokal auf deinem Rechner — es gibt weder ein Nutzerkonto noch eine Synchronisierung in eine Cloud. Eine ausführliche Beschreibung aller Ansichten findest du in der Dokumentation.

Deine Daten bleiben auf deinem Gerät

FinanzGecko speichert alles in einer einzigen, AES-256-GCM-verschlüsselten Datei; der Schlüssel liegt im Schlüsselbund deines Betriebssystems. Die App sendet keine Telemetrie und keine Absturzberichte. Sie stellt genau zwei Netzwerkanfragen: aktuelle Wechselkurse für Fremdwährungskonten und – nur wenn du sie manuell auslöst – eine Prüfung auf neue Versionen. Details dazu stehen in der Datenschutzerklärung. Da es keinen Server gibt, liegt die Sicherung bei dir: Exportiere regelmäßig ein Backup, dann lässt sich dein Stand jederzeit auf einem anderen Rechner wiederherstellen.

Updates und Versionshinweise

Neue Versionen erscheinen als GitHub-Release mit Änderungsliste. Ein Update installierst du, indem du die neue Datei herunterlädst und die alte ersetzt — deine bestehenden Daten bleiben dabei erhalten. Da FinanzGecko quelloffen ist, kannst du jederzeit im Quellcode nachlesen, was die Anwendung tut, oder sie selbst aus den Quellen bauen.
